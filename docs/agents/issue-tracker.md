# Work references for this delivery

The approved AFK work is supplied as a local spec: `docs/plans/afk-workflow-reliability.md` and `docs/plans/afk-workflow-implementation.md`. P0–P8 identify work packages in that plan, not external issue IDs. Record progress in `docs/plans/afk-workflow-progress.md` and link each package's acceptance plan/report.

No external tracker has been selected for this repository. This delivery does not publish issues or messages to the Sandcastle upstream tracker. Future tracker setup can migrate these references without recreating settled requirements.

## Completion and persistence

Plans, reports and progress records are repository files. Update them before the final package commit, or make a follow-up commit when a checkpoint already exists. A passing test run or saved Markdown file alone does not establish committed delivery. Keep unfinished work visible until its required verification succeeds.
